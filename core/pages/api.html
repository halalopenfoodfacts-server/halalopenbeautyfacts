API publique

Une API JSON en lecture seule, servie depuis notre propre base. Merci de rester raisonnable : 20 requêtes par seconde au maximum, et mettez les réponses en cache.

Point d'accèsDescription
GET /proxy/v2/search?q=…Recherche plein texte. Paramètres : q, prefix=1 (saisie partielle), page (≤ 200), page_size (≤ 100), sort_by (unique_scans_n, last_modified_t, product_name), fields. Un code-barres dans q renvoie directement le produit (barcode_match).
… &is_halal=1 / &is_excluded=1Produits au statut halal / haram (aussi : &halal_status=doubtful).
… &labels_tags=en:organicFiltres par tag exact : labels_tags, categories_tags, countries_tags (répétables){{#if site.features.nutrition}}, nutriscore=a, nova=1, palm_oil_free=1{{/if}}.
GET /proxy/v2/product/{code}.jsonFiche complète, dont halal_status et halal (raisons détaillées).
GET /proxy/statsChiffres clés. Répond 503 + Retry-After pendant le calcul.
GET /proxy/facets/{type}.jsoncountries, labels, categories, contributors.
GET /proxy/top · /proxy/recentProduits les plus consultés / modifiés récemment (page_size ≤ 50).

Statut halal (halal_status)

halal
Label halal déclaré, ou ingrédients renseignés sans alcool ni porc.
haram
Alcool ou porc dans les ingrédients, ou label d'alcool / non halal déclaré.
doubtful
Labels contradictoires, ou ingrédient d'origine incertaine (gélatine, E120, E471, présure…) sans label halal.
unknown
Liste des ingrédients absente.

Ces statuts ne sont pas des certifications. Données sous licence ODbL : citez {{site.name}} et {{site.upstream.name}}.

Exemple

curl "{{site.domain}}/proxy/v2/search?q=couscous&is_halal=1&page_size=5&fields=code,product_name,halal_status"
